# Excel Survey Template Examples

Worked examples for the [Excel Template Tutorial](../../docs/EXCEL_TEMPLATE_BASICS.md) —
building a survey JSON template by filling in an Excel codebook workbook and importing
it in **Template Editor** (Import Template Source), rather than importing raw
respondent data (that flow is documented separately, see
[Converter — Survey Import](../../docs/studio/converter_survey.md)).

To start a template of your own from scratch, use the canonical blank workbook at
[official/create_new_survey/survey_import_template.xlsx](../../official/create_new_survey/survey_import_template.xlsx)
instead of copying either example below.

## `basic/`

- `survey_import_basic_example.xlsx` — a filled-in workbook for a small 4-item
  single-version instrument ("Daily Mood Check").
- `survey-mood.json` — the resulting template, generated by importing the workbook
  above. Compare your own import output against this file.

## `advanced/`

- `survey_import_advanced_example.xlsx` — a filled-in workbook for a 10-item
  instrument with a 5-item short form, including one item-level scale override for
  the short form.
- `survey-wellcheck.json` — the resulting template, including `Study.VariantDefinitions`,
  per-item `ApplicableVersions`, and a `VariantScales` override.

Both `.json` files were generated by actually running the workbooks through PRISM's
importer and validating the result (`prism-validator --validate-templates`) — they are
known-good, not hand-written.
