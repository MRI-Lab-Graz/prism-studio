Global Settings
Root folder for survey templates. Must contain a survey/ subfolder with JSON templates: 
my-library/
  survey/
    survey-phq9.json
    survey-gad7.json
Default: App's built-in official/library/ folder. Can be changed to a shared location (Nextcloud, GitLab, etc.).
Projects can override this with templateLibraryPath in .prismrc.json.
Your own templates, shared by all your projects but never part of one. Same layout as the other libraries (survey/, biometrics/ subfolders). Order of use: the project's library, then this one, then the global library. A conversion copies the templates it used into the project, so shared projects stay complete.
Folder with your recipes. Must contain a survey/ (or biometrics/) subfolder with recipe JSON files: 
my-recipes/
  survey/
    recipe-phq9.json
    recipe-gad7.json
Default: official/recipe/ folder. Can be changed to a shared location.
Recipes are automatically used in the "Analysis Outputs" tool.
Survey Template Locations
Global Survey Templates (Read-only)
Not configured
Path: */survey/*.json
Project Survey Templates (Editable)
Select a project
Path: project/library/survey/*.json (Root level)
Survey templates from both locations are merged. Project templates take priority over global templates with the same name.
