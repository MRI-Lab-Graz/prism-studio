Add your own modalities

Every PRISM modality is a plain JSON schema. Describe a new instrument, measure, or sidecar field in a schema and validation follows it, with no code changes.

Many modalities, one project

Surveys, biometrics, physiology, eye tracking, events, and environmental context ship ready to use, side by side in the same subject and session layout.

Convert messy source data

Import Excel, CSV, TSV, LimeSurvey, Pavlovia, Presentation logs, and physiological recordings without hand-building folders or filenames.

Validate against the schemas

Check every file and sidecar against its modality schema and BIDS naming rules, with clear error messages and automatic fixes where safe.

Stay compatible with BIDS apps

PRISM adds modalities and metadata on top of BIDS without giving up standard BIDS validators and downstream tools.

Compute derived scores

Build scoring recipes for questionnaires and assessments instead of maintaining fragile spreadsheet formulas.

Privacy-safe export for analysis

Generate analysis-ready exports such as SPSS, CSV, TSV, labels, and codebooks with anonymization and MRI metadata/privacy safeguards.

Full DataLad provenance support

Initialize tracked projects, save snapshots, and record DataLad-backed mutation runs for critical dataset updates.

Rename and de-identify subjects in bulk

Rewrite subject or BIDS entity IDs across an entire dataset in one batch, with DataLad-aware per-subject commits and built-in collision checks so renamed or merged IDs never silently overwrite each other.

Sync to a remote DataLad server

Push a tracked project to a remote RIA store with one click, verify every file transferred intact, and disconnect safely once the upload is confirmed.
