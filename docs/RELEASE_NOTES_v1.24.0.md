# PRISM Studio v1.24.0

## Highlights

- **A new project needs its required metadata.** Create Project and Save wait for the required fields and name the missing ones.
- **Init on a BIDS dataset keeps its own `CITATION.cff` and `README.md`**: authors and citation metadata are taken into the project
  instead of being replaced by placeholders.
- **Time or content sessions**, with a per-participant session order.
- **Settings page** (gear icon), with DataLad opt-in for new projects.
- **Template editor and converters**: one template choice in the CLI and Studio, complete templates required, a personal library.
- **Studio and the command line write the same files** for export, `survey convert`, physio and biometrics.

See `CHANGELOG.md` for the full list of changes.

## Downloads

- Windows: `prism-studio-Windows.zip`
- macOS (Apple Silicon): `prism-studio-macOS-AppleSilicon.zip`
- Linux: `prism-studio-Linux.zip`

## macOS First Launch

If macOS blocks the app on first launch, open the extracted release folder and double-click:

`Prism Studio Installer.app`

If App Translocation prevents auto-detection, the installer asks you to select `PrismStudio.app` once.

Fallback:

`Open Prism Studio.command`
