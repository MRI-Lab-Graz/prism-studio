# Dataset description (`dataset_description.json`)

The BIDS root file that names and licenses the dataset. PRISM keeps it BIDS-valid and
adds FAIR expectations on top, so a PRISM project can be shared without extra cleanup.

## Validation

| Code | When |
| --- | --- |
| `PRISM001` | The file is missing (auto-fixable) |
| `PRISM003` | The file is not valid JSON or lacks a required field |
| `PRISM006` | FAIR gaps: `Description` of at least 50 characters, `License`, `EthicsApprovals`, `Funding`, at least 3 `Keywords`, `Authors` with ORCID / affiliation |

See [Error codes](../ERROR_CODES.md).

## Keeping it in sync with `CITATION.cff`

`CITATION.cff` is the citation-focused file. Do not repeat citation information in both:
`Name` and `DatasetDOI` are kept in sync, while `License`, `Authors`,
`HowToAcknowledge` and `ReferencesAndLinks` are written to `dataset_description.json`
only when no `CITATION.cff` exists. Edit both through the Projects page, not by hand,
so they cannot drift.
